# 通途（Tongtu）macOS 新机部署安装说明

本文档适用于在 **全新 Mac** 上安装并配置通途客户端，版本 **2.5.3**。

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | macOS 11 及以上 |
| 芯片架构 | **Apple Silicon（M 系列）** |
| 权限 | 首次启用 TUN 模式需管理员密码 |
| 网络 | 可访问订阅链接或已有备份文件 |

> **注意：** 当前安装包为 `aarch64` 版本，**不支持 Intel 芯片 Mac**。安装包未做 Apple 开发者签名，首次打开需额外步骤（见下文）。

---

## 二、获取安装包

从项目构建产物或分发渠道获取 DMG 文件：

```
通途_2.5.3_aarch64.dmg
```

本地构建时，执行 `pnpm build` 后产物位于：

```
dist-mac/通途_2.5.3_aarch64.dmg
```

将 DMG 拷贝到新 Mac（U 盘、网盘、内部分发均可）。

---

## 三、安装步骤

### 1. 安装应用

1. 双击 `通途_2.5.3_aarch64.dmg` 打开镜像
2. 将 **通途** 拖入 **应用程序（Applications）** 文件夹
3. 弹出 DMG 镜像（可选）

### 2. 首次打开（绕过 Gatekeeper）

由于安装包未签名，系统可能提示「无法打开」或「来自身份不明的开发者」。任选以下方式之一：

**方式 A（推荐）：右键打开**

1. 在「应用程序」中找到 **通途.app**
2. **按住 Control 键点击**（或右键）→ 选择 **打开**
3. 在弹窗中再次点击 **打开**

**方式 B：终端移除隔离属性**

```bash
xattr -cr /Applications/通途.app
```

然后正常双击打开即可。

### 3. 安装系统服务（启用 TUN 必需）

首次启动若弹出 **「需要更新系统服务」** 或 **「服务不可用」**：

1. 点击 **修复服务**（或类似按钮）
2. 在系统弹窗中输入 **管理员密码** 并确认
3. 等待安装完成，重启通途或重新打开应用

> **说明：** TUN / 虚拟网卡模式依赖本地特权系统服务，与远程节点服务器无关。仅使用「系统代理」模式时，可不安装此服务。

### 4. 导入配置

任选一种方式：

**方式 A：订阅链接（推荐）**

1. 打开通途 → **配置（Profiles）**
2. 点击 **新建** → 粘贴订阅 URL
3. 保存后选中该配置并启用

**方式 B：从备份恢复**

若有 `.zip` 或备份目录，在设置中使用 **导入/恢复** 功能，或手动将备份内容放入配置目录（见「数据目录」）。

**方式 C：从旧版 Clash Verge 迁移**

若本机曾安装 Clash Verge，通途 **首次启动** 会自动尝试从旧目录迁移数据。也可手动复制：

```bash
# 旧目录（Clash Verge）
~/Library/Application Support/io.github.clash-verge-rev.clash-verge-rev

# 新目录（通途）
~/Library/Application Support/com.yitong.tongtu
```

## 四、日常使用

### 代理模式说明

| 模式 | 说明 | 是否需要系统服务 |
|------|------|------------------|
| **系统代理** | 修改系统 HTTP/HTTPS/SOCKS 代理 | 否 |
| **TUN 模式** | 虚拟网卡，接管全部流量 | **是** |

建议流程：

1. 导入并选中订阅配置
2. 在首页开启 **系统代理** 或 **TUN**（按需求）
3. 选择节点并测试连通性

### 菜单栏图标

通途会在菜单栏显示图标，关闭主窗口后应用仍在后台运行。如需完全退出：

- 点击菜单栏图标 → **退出**，或
- 在「活动监视器」中结束 **通途** 进程

> 安装或覆盖升级前，请先 **完全退出** 通途（含菜单栏），否则可能提示「通途已打开」导致安装失败。

---

## 五、数据目录

通途使用独立配置目录，与 Clash Verge **不共用**：

```
~/Library/Application Support/com.yitong.tongtu
```

备份目录名：`tongtu-backup`（在用户目录下的备份相关路径中）。

迁移或重装时，保留此目录即可保留订阅、规则与设置。

---

## 六、注意事项

1. **不要与 Clash Verge 同时运行**  
   两者可能争用同一系统服务，导致 TUN 异常或服务冲突。新机请只安装通途。

2. **仅 Apple Silicon**  
   当前 DMG 为 `aarch64`，Intel Mac 无法使用此包。

3. **未签名应用**  
   每台新 Mac 首次打开需「右键打开」或执行 `xattr -cr`（见第三节）。

4. **系统服务命名**  
   底层仍使用上游 `clash-verge-service` 组件，系统内路径可能仍含 `clash-verge` 字样，属正常现象，不影响通途独立配置目录 `com.yitong.tongtu`。

5. **升级安装**  
   覆盖安装前退出通途（含菜单栏），再拖入新版本到「应用程序」即可；配置目录会自动保留。

## 七、常见问题

### Q1：提示「通途已打开」，无法安装

**原因：** 应用在菜单栏后台运行。

**处理：** 菜单栏图标 → 退出，或在活动监视器中结束进程后重新安装。

### Q2：TUN 无法开启 / 「服务不可用」

**原因：** 系统服务未安装，或安装时取消了管理员授权。

**处理：**

1. 完全退出通途后重新打开
2. 点击 **修复服务**，输入管理员密码
3. 确认未同时运行 Clash Verge

### Q3：菜单栏图标有黑角或仍是旧图标

**处理：** 确保安装的是最新构建的 DMG；完全退出后重新打开。若仍异常，删除旧版后重装。

### Q4：订阅导入后无法联网

**处理：**

1. 确认配置已 **选中并启用**
2. 检查节点延迟与可用性
3. 先尝试 **系统代理**，再试 TUN
4. 查看通途内 **日志** 是否有 DNS 或规则错误

### Q5：如何彻底卸载

```bash
# 1. 退出通途（菜单栏 → 退出）

# 2. 删除应用
rm -rf /Applications/通途.app

# 3. 删除配置（可选，会清除所有订阅与设置）
rm -rf ~/Library/Application\ Support/com.yitong.tongtu

# 4. 删除系统服务（可选，仅当不再使用 TUN 且确认无其他依赖）
# 需管理员权限，一般保留不影响系统
```
